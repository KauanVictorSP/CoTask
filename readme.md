# CoTask — Gerenciador de Rotinas e Atividades

O **CoTask** é uma aplicação web desenvolvida para auxiliar na organização de tarefas, atividades e rotinas pessoais. O projeto busca oferecer uma experiência simples e intuitiva, combinando funcionalidades de produtividade com uma identidade visual inspirada na estética Cyberpunk.

## Acesse o projeto

🌐 **Aplicação online:** https://kauanvictorsp.github.io/CoTask/

💻 **Repositório:** https://github.com/KauanVictorSP/CoTask

## Funcionalidades

- **Gerenciamento de rotinas:** organização das atividades do usuário.
- **Calendário interativo:** visualização e seleção de datas.
- **Cadastro de atividades:** criação de tarefas com informações personalizadas.
- **Edição e exclusão:** gerenciamento das atividades cadastradas.
- **Persistência de dados:** armazenamento das informações utilizando LocalStorage.
- **Pesquisa e filtros:** localização e organização das atividades.
- **Integração com API externa:** utilização de dados de serviços externos.
- **Convites por e-mail:** envio de convites para outras pessoas.
- **Notificações personalizadas:** feedback visual para ações realizadas na aplicação.

## Como executar localmente

1. Faça o clone do repositório:

   ```bash
   git clone https://github.com/KauanVictorSP/CoTask.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd CoTask
   ```

3. Abra o arquivo `src/index.html` no navegador.

## Publicação

A aplicação é hospedada pelo **GitHub Pages**, utilizando GitHub Actions para publicar automaticamente o conteúdo da pasta `src/` a cada atualização na branch `main`.
